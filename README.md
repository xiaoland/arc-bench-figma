# Minimal Figma Design · ARC-Bench task

这是一个复现 Figma Design 核心工作流的 ARC-Bench 任务。当前版本包含 183 个需求节点和 236 个可执行的 Playwright 场景。

从 [Releases](https://github.com/xiaoland/arc-bench-figma/releases) 下载版本 ZIP。生成时将 `arc-bench/figma/requirements/` 作为 ARC 的输入目录。启动候选应用后，从完整任务目录运行独立评测。

任务目录内有[运行说明](arc-bench/figma/README.md)和[内容清单](arc-bench/figma/manifest.json)。
