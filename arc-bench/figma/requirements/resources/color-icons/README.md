# Color icons

These named assets are reusable references for glyph geometry and native drawing boxes. The SVGs inherit currentColor from the control. Button hit areas are separate.

| Name | Control | Native box |
|---|---|---|
| [SampleColor](SampleColor.svg) | Start the eyedropper for the open Color target | 24 × 24 |
| [EffectClose](../effects-icons/EffectClose.svg) | Close Color | 24 × 24 |
| [ChevronDown](../layout-icons/ChevronDown.svg) | Open the color format choices | 24 × 24 |

SampleColor comes from the Figma Color popup observed on 2 November 2026. Close and the format arrow match the existing assets. [Manifest](manifest.json) records the source and file identities.
