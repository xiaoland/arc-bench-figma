# Layout icon resources

This subset contains SVG assets observed in the Figma Design Layout panel on 28 October and 2 November 2026. Names below are local resource identifiers. The manifest retains Figma identifiers where the page exposes them.

These SVGs are reusable references at the stated CSS sizes. They can be referenced by URL, imported, or embedded inline. Inline SVG inherits the control color through `currentColor`. A selected control supplies its background and icon color.

The SVG box and its visible mark have different sizes. A 24 × 24 SVG can contain a mark about 12 pixels wide. Give the SVG its full box. For a flex container, use `flex: none` on that box.
