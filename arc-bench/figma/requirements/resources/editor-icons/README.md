# Editor icon resources

These SVGs are reusable references for the glyph and its native drawing box. The SVGs inherit currentColor from the control.

Tool and Nav assets identify toolbar and navigation buttons. Menu assets identify the leading illustration in each tool-menu row. MenuCheck is the separate 16-pixel selected-option mark. The leading illustrations use their 24-pixel boxes. Each row has separate mark and illustration slots.

Tool-group arrows reuse [ChevronDown](../layout-icons/ChevronDown.svg) in its 24-pixel box, centered in the 16-pixel-wide trigger. The Scale toolbar button reuses [ScaleTool](../position-icons/ScaleTool.svg) at 24 pixels.
