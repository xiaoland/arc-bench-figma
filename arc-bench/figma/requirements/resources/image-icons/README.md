# Image icon resources

These SVGs are reusable references with native 24 × 24 CSS-pixel drawing boxes. The SVGs inherit currentColor from the control.

| Resource | Use |
|---|---|
| [ImageCrop](ImageCrop.svg) | The image layer Crop action |
| [CropAspectRatio](CropAspectRatio.svg) | Crop toolbar ratio picker |
| [ImageRotate90](ImageRotate90.svg) | Rotate the source image inside its layer |

The Crop toolbar reuses [ResizeToFit](../layout-icons/ResizeToFit.svg) and [Check](../layout-icons/Check.svg). Menu arrows use the common icon set. [Manifest](manifest.json).
