# Component icons

These observed SVGs are reusable references for the glyph and its native drawing box. The SVGs inherit currentColor from the control. The control has a separate hit area.

| Asset | Role | Drawing box |
|---|---|---|
| [CreateComponent](CreateComponent.svg) | Create a main component | 24 × 24 |
| [PropertyText](PropertyText.svg) | Text property type | 24 × 24 |
| [ApplyProperty](ApplyProperty.svg) | Open a property binding picker | 24 × 24 |
| [ResetInstance](ResetInstance.svg) | Restore current source values | 24 × 24 |
| [DetachInstance](DetachInstance.svg) | Detach the outer instance | 24 × 24 |

Add uses paint-icons/PaintAdd.svg. Edit property uses paint-icons/EditStyle.svg at its native 12 × 14 size. [Manifest](manifest.json).
