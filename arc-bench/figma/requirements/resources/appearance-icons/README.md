# Appearance icon resources

These SVGs are reusable references with native 24 × 24 CSS-pixel drawing boxes. The SVGs inherit currentColor from the control.

| Resource | Control |
|---|---|
| [LayerOpacity](LayerOpacity.svg) | Layer opacity prefix |
| [CornerRadius](CornerRadius.svg) | Uniform radius prefix and Individual corners button |
| [CornerTopLeft](CornerTopLeft.svg) | Top-left radius prefix |
| [CornerTopRight](CornerTopRight.svg) | Top-right radius prefix |
| [CornerBottomLeft](CornerBottomLeft.svg) | Bottom-left radius prefix |
| [CornerBottomRight](CornerBottomRight.svg) | Bottom-right radius prefix |
| [CornerSmoothing](CornerSmoothing.svg) | Open Corner smoothing |

The two CornerRadius uses have the same observed geometry. Close reuses [EffectClose](../effects-icons/EffectClose.svg). Layer visibility uses [PaintVisible](../paint-icons/PaintVisible.svg) and [PaintHidden](../paint-icons/PaintHidden.svg). [Manifest](manifest.json).
