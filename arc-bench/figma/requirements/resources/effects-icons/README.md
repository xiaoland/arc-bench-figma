# Effects icon resources

These SVGs are reusable references for the glyphs and their native 24 × 24 CSS-pixel drawing boxes. In the SVGs, currentColor supplies the primary color and --icon-tertiary supplies the secondary mark.

| Resource | Use |
|---|---|
| [DropShadow](DropShadow.svg) | Shadow row and popup title |
| [ShadowBlur](ShadowBlur.svg) | Blur field prefix |
| [ShadowSpread](ShadowSpread.svg) | Spread field prefix |
| [EffectClose](EffectClose.svg) | Close the settings popup |

Add, visibility, Remove, and drag handles use the shared [Paint assets](../paint-icons/README.md). X and Y are text prefixes. [Manifest](manifest.json).
