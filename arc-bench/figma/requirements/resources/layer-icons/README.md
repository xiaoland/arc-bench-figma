# Layer symbols

These named SVGs are reusable glyph references. The row supplies the symbol color. A type or action symbol uses a 16 × 16 box with a separate hit area.

LayerComponent identifies a main component or a component set. LayerVariant identifies a main component inside a set. LayerInstance identifies an instance. LayerVariant supports an optional `--layer-symbol-interior` color; it defaults to the outline color.

## Geometry thumbnails

Shape and imported vector rows show a small outline of their geometry, centered in a 16 × 16 slot. The outline follows the object proportions and direction. Line and Arrow show their line direction. The three Outline files are observed examples, each in its original 10 × 10 box. They illustrate the thumbnail style; the current object supplies the outline.

## Action visibility

Layers defines when the lock and visibility controls appear and which objects each action changes. These assets supply only their symbols. Paint rows retain their separate Paint icon assets.
