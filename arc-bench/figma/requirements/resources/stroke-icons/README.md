# Stroke icon resources

These SVGs are reusable references for the native drawing boxes and glyph geometry. In the SVGs, currentColor supplies the primary color and --icon-tertiary supplies the secondary diagram line.

StyleSolid and StyleDashed appear before the selected Style label and in its menu. Custom uses text. MiterAngle is the angle field prefix.

Menu icons, side-width prefixes, settings, swap, and join controls use 24 × 24 CSS-pixel boxes. Dash cap uses EndpointNone, EndpointSquare, and EndpointRound, in that order.

EndpointPreview files have a 200 × 24 drawing box. Display the first part at native scale inside a clipped field: the endpoint stays at the left and the path continues to the right. Mirror the clipped diagram for End point. The field width controls the visible path length.
