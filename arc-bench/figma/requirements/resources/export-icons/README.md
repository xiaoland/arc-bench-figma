# Export icons

[ExportOptions](ExportOptions.svg) is a reusable glyph reference for the current export row's Options button. Its native drawing box is 24 × 24. The SVG inherits currentColor from the control.

Add and Remove use paint-icons/PaintAdd.svg and PaintRemove.svg. Options Close uses effects-icons/EffectClose.svg. Their observed paths and 24 × 24 boxes match the existing assets. The control hit area remains separate. [Manifest](manifest.json).
