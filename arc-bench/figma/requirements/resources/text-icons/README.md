# Text icon resources

These SVGs are reusable references with native 24 × 24 CSS-pixel boxes. The control supplies the glyph color and selected background. The SVGs inherit the glyph color through currentColor.

| Control | Resource |
|---|---|
| Auto width | [TextAutoWidth](TextAutoWidth.svg) |
| Auto height | [TextAutoHeight](TextAutoHeight.svg) |
| Fixed size | [TextFixedSize](TextFixedSize.svg) |
| Text horizontal alignment | [TextAlignLeft](TextAlignLeft.svg), [TextAlignCenter](TextAlignCenter.svg), [TextAlignRight](TextAlignRight.svg) |
| Text vertical alignment | [TextAlignTop](TextAlignTop.svg), [TextAlignMiddle](TextAlignMiddle.svg), [TextAlignBottom](TextAlignBottom.svg) |
| Line-height prefix | [TextLineHeight](TextLineHeight.svg) |

Text alignment positions text inside its box. Position alignment moves layers. Their icons belong to their respective controls. Use layout-icons/ChevronDown.svg for a menu arrow and paint-icons/ApplyStyles.svg for the Style picker. [Manifest](manifest.json).
